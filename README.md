# 사이비 탈출 — 교주의 폰 (메신저 시뮬레이션 게임)

사이비 교단의 사도가 되어 교주의 스마트폰을 훔쳤다. 교주인 척 메시지를 보내 신도들을 속이고, 폰 안의 단서를 모아 빠져나가자.

**▶ 플레이: (https://haein0068.github.io/aigame2/)/**

> 설치 없이 브라우저(폰 권장)에서 바로 실행됩니다. 이 게임은 픽션이며 실존 인물·단체와 관계가 없습니다.

## 플레이 방법
1. 잠금화면을 위로 밀고, 비밀번호 4자리를 아무거나 입력하면 시작합니다.
2. 메시지 앱에서 교주인 척 자유롭게 답장하세요. 말투가 어색하면 상대가 의심합니다.
3. 전화, 캘린더, 이미지, 인터넷, 은행 앱에서 단서를 찾아보세요.
4. 시간이 지나면 폰에 이상한 일이 생깁니다.

## 내 버전으로 만들기 (Fork)
1. 이 저장소 오른쪽 위의 **Fork** 를 누릅니다.
2. 내 저장소에서 **Settings → Pages** 로 들어가 Source를 *Deploy from a branch*, Branch를 `main` / `(root)` 로 선택하고 **Save** 합니다.
3. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 에서 내 버전이 열립니다.

## 내용 수정하기
`index.html` 파일 맨 위 **[설정 영역]** 에서 글만 바꾸면 됩니다.

| 이름 | 내용 |
|---|---|
| `CHARACTERS` | 인물, 키워드 답장, 기본 답장 |
| `BOND` | 호감도가 쌓이면 나오는 개인 사정 이야기 |
| `STORY_TIMELINE` | 시간에 따라 도착하는 메시지 |
| `CALLS`, `CALLSCRIPT` | 걸려오는 전화와 통화 자막 |
| `GALLERY`, `BANK`, `NEWS`, `CALEV` | 이미지 설명, 은행 내역, 뉴스, 일정 |
| `GAME_CONFIG` | 이상현상 시각, 전화 간격 등 |
